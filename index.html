Keyboard Shortcuts & Platforms

MD File View runs seamlessly across macOS, Windows, and Linux. The codebase is configured with Capacitor for 1-click mobile builds on Android & iOS.

ShortcutAction
Ctrl / Cmd + OOpen .md File from disk
Ctrl / Cmd + SSave Document to disk
Ctrl / Cmd + NCreate New Document
Ctrl / Cmd + EToggle View Mode ↔ Edit Mode
Ctrl / Cmd + FFind / Search in document
Ctrl / Cmd + BToggle Table of Contents sidebar
Ctrl / Cmd + PExport to PDF (Print)
Tab / Shift+TabIndent / Outdent in Editor
📱 Android & iOS Build:
Run npm run build, then npx cap add android or npx cap add ios to create native mobile studio projects!
